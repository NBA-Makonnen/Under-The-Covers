# Under The Covers

A book-discovery and recommendation site — see what's popular right now, filter by genre/year/author, get recommendations based on what you like, and find where to get a book you're interested in.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Deployed on Vercel

## Data sources (planned)

- **NYT Books API** — bestseller lists for "what's popular right now"
- **Google Books API / Open Library API** — search, metadata, covers, filtering, and outbound links

## Getting Started

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) to view it.
